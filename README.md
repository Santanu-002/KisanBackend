# Kisan Backend

The Python FastAPI backend for the Kisan App, providing robust JWT-base authentication, SMS OTP delivery, and user tracking.

## Prerequisites
- Python 3.11+
- Redis Server (Must be running for OTP rate-limiting and session management)

## Setup & Run

1. **Initialize Virtual Environment:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Environment Configuration:**
   Create a `.env` file in this exact root directory and configure the following required secrets.
   ```env
   PROJECT_NAME="Kisan Backend API"
   SECRET_KEY="<YOUR_LONG_SECURE_HMAC_SECRET_KEY>"
   
   # Database Connections
   REDIS_URL="redis://localhost:6379/0"
   
   # Twilio SMS Configuration
   TWILIO_ACCOUNT_SID="<YOUR_TWILIO_SID>"
   TWILIO_AUTH_TOKEN="<YOUR_TWILIO_AUTH_TOKEN>"
   TWILIO_PHONE_NUMBER="<YOUR_TWILIO_TRIAL_OR_PAID_NUMBER>"
   
   # Note: For App Store Review/Testing without network costs, 
   # use the mock phone number: +911111111111 with OTP: 222222
   ```

4. **Launch the Server:**
   ```bash
   uvicorn main:app --reload --host 0.0.0.0 --port 8000
   ```
   The backend will be available at `http://127.0.0.0:8000`. You can test endpoints via the Swagger UI autogenerated at `http://127.0.0.0:8000/docs`.
